# 차배달탁송 새 홈페이지

## 페이지 고치는 방법
- 각 페이지 본문은 `src/` 폴더에 있습니다.
- 맨 위 메뉴·바닥글·오른쪽 버튼은 `tools/layout.html` 한 곳에만 있습니다.
- 고친 뒤 `python3 tools/build.py`를 실행하면 맨 위에 완성된 `.html` 파일이 다시 만들어집니다.

## 문의 입력칸
- 문의는 구글 시트 "홈페이지 견적 문의"에 쌓이고, 들어올 때마다 Gmail로 알림이 옵니다.
- 시트에 붙이는 프로그램: `tools/google-apps-script.gs`
- 웹 앱으로 배포해서 받은 주소를 `js/contact.js` 맨 위 `SHEET_URL`에 적습니다.
- 비워 두면 문자(010-2133-5879)로만 보냅니다.
